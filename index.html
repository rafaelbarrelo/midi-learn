        MIDI Learn

        Map any MIDI controller to anything in LUNA.

        Learning a mapping

        Press Learn in a section's header (L for Mappings). Then, in either order: touch a control in LUNA (or pick one in Parameters), and move a knob, fader or pad. A learn bar opens at the top of that section while it learns.

        Parameter
        What will be controlled: the control you touched or picked.
        MIDI
        What controls it. Fills in when you move a control on your controller, or type it: choose CC, Note or Bend, a number (a note can be 60 or C3) and a channel (Any listens on all 16), then Assign or Enter.
        Hold
        Turn on Hold (next to Learn while it learns) (or Shift-click / right-click Learn) to keep learning: after each mapping it waits for the next, so you can map one control after another. Click as many parameters as you like before turning a knob; the last one you clicked is the one that gets mapped. The button turns red (Holding). Turn Hold off, press the button, Stop or Esc to finish.
        Done / Esc
        Stops learning.

        One MIDI control drives one thing: learning it again moves it, from any section.

        Click & Turn

        One knob that controls whatever you last clicked or dragged in LUNA: a fader, a pan, a send, a mute or a plugin parameter. Learn it once, then click around. LUNA doesn't report what the mouse hovers over, only what you touch.

        Pin
        Stay on the current control; clicks elsewhere don't move it.
        Feedback
        On by default. When Click & Turn moves to a new control, that control's value is sent to the knob, so a motorized knob (Roto-Control) turns to it.
        Save with this session
        Keep this knob inside the LUNA session, so it comes back with the session file. Off: one Click & Turn knob shared by every session.
        ×
        Removes Click & Turn.
        Mappings

        Fixed mappings: this knob always drives that control on that track, or runs that command.

        All / Session / Global
        Filter the list. Session mappings are saved inside this LUNA session and come back when it reopens, on any machine. Global mappings work in every session.
        Commands
        While learning, the Commands button in the learn bar opens the list of LUNA commands right there (Play, Record, Undo…), so you can pick one without scrolling down to Parameters.
        Templates
        In the top bar: save or load your whole layout, every section (see Templates).
        Channel Focus

        A dedicated channel strip on your controller. Its mappings remember which control on a track (the fader, pan, a send, insert 1's Input…) and act on the focused track: the one selected in LUNA. Select another track and the same knobs control it.

        Selected / Lock
        Follow LUNA's selection, or lock the focus to one track.
        Feedback
        On or off for every Channel Focus mapping at once. On: selecting a track sends its values, so motorized knobs jump to it.
        Plugins
        A plugin parameter only works on tracks with the same plugin in the same insert slot; elsewhere its row reads "not on …".
        Save with this session
        Keep Channel Focus inside the LUNA session, so each session can have its own layout. Off: one layout shared by every session.
        Stepping tracks
        Map Select next track and Select previous track (Parameters → Commands) to two buttons.
        Plugins

        Plugin maps: one map per plugin type (UA 1176, Pro-Q…), used by whichever instance of it is in focus. Map your knobs once and they control any 1176 you open, in any session (or only this one, with Save with this session).

        Focus
        Like Channel Focus: select a track and its plugin with a map is in focus. Turning a knob in another plugin's window switches to that instance until you select another track. Opening a plugin window alone can't: LUNA doesn't tell add-ons which plugin windows are open, only what you touch. The menu can lock one instance.
        Learn
        Press Learn, turn a knob in the plugin's window, then one on your controller. Turn on Hold (next to Learn while it learns) to map several parameters in a row.
        A layer
        While a plugin with a map is in focus, its knobs win; the same knobs fall back to your other mappings when it isn't. So eight knobs can mean different things for every plugin.
        Feedback
        On by default: focusing another instance sends its values, so motorized knobs jump to them.
        Save with this session
        Keep the plugin maps inside the LUNA session. Off: one set of maps shared by every session.
        Saved maps
        Every plugin with a map, with how many controls it has. × deletes a map (press twice).
        Templates

        Templates (top bar) save your whole controller layout, every section: this session's mappings, global mappings, Channel Focus, Click & Turn and plugin maps. Load merges a template in; Replace clears those sections first. Export/Import move templates and everything global to another machine.

        A mapping's settings (the ⌄ on a row)
        MIDI
        Retype the message, number and channel. Moving it onto another mapping's control replaces that one.
        Mode: Follow
        Knobs and faders set the value. Buttons fire on the press (for buttons that send on, then off on release).
        Mode: Toggle
        Each press flips a switch, or toggles a control between its range ends. Buttons mapped to commands fire on every press of a latching button (sends on, then off on the next press, like a Roto button set to TOGGLE).
        Range
        The lowest and highest MIDI value (0–127) the control can reach. Drag the two caps, or use the arrow keys (Shift for 10).
        Invert
        Turning up turns the control down.
        Global
        Use this mapping in every session (Mappings only).
        Feedback
        Send LUNA's value back to the controller, so motorized knobs and button lights follow. Off unless turned on (on by default in Channel Focus and Click & Turn). A ↔ on the row shows it's on.
        Device
        The MIDI input this mapping listens to, and where its feedback goes (the output of the same name). Any input listens to all; feedback then goes to whichever device it last heard from.
        ×
        Deletes the mapping.
        Parameters

        Everything you can map, per track: strip controls (fader, pan, mute, solo), sends, cues, automation modes, plugins, and LUNA commands. Click one while learning to pick it, or click one any time to start learning it. Search filters the list; Rescan reads the session again.

        Plugins
        Listed by name; touch a knob in the plugin's window while learning to map it. Their parameters are read one at a time, never all at once (that can hang LUNA).
        Pan
        A mono channel has one Pan. A stereo channel lists Pan L and Pan R (Stereo Pan) and Balance, one knob that moves both (Balance). A pan mapped on one kind of channel finds the pan on the other, so Channel Focus pans keep working as the focus moves between mono and stereo tracks.
        Automation
        Off / Read / Write / Touch / Latch buttons, Next automation mode (steps through them), and Automation mode (a knob with five zones).
        Commands
        Play/Stop, Record, Loop, Undo, Redo, Save, Select next/previous track and more. Reset parameter to default puts the parameter in focus (the one you last touched in LUNA, or last moved with Click & Turn or a Channel Focus knob) back to LUNA's default, as one undo step.
        Feedback and motorized controllers

        Feedback sends plain 7-bit CC (or note on/off for notes) to the output with the same name as the mapping's device. To avoid loops: nothing is sent while you're moving that control; the controller's own motor echo is ignored; and a value is never sent twice.

        Roto-Control: use MIDI mode, set each knob's resolution to COARSE in Roto-Setup (14-bit FINE values make knobs jump), and match the knob's channel and CC to the mapping.

        Top bar
        MIDI
        Which input MIDI Learn listens to: all, or one device. It is the helper, Web MIDI or LUNA itself, whichever is available (see the MIDI chip's tooltip).
        LUNA
        Green when connected.
        ?
        This help.
        Colour
        The background colour; text turns white on dark ones.
        Keys
        L
        Learn in Mappings.
        Esc
        Stop learning, or close a menu.
        Undo, play, record
        LUNA's own shortcuts keep working while MIDI Learn has the focus.
